# CrimeLens – Exploratory Data Analysis of Los Angeles Crime Data (2020–2024)

## Project Overview
CrimeLens is an Exploratory Data Analysis (EDA) project that analyzes Los Angeles crime data from 2020 to 2024 to identify crime patterns and trends.

## Objectives
- Explore crime patterns across different crime categories.
- Analyze crime distributions across LAPD areas.
- Examine temporal patterns in reported crimes.
- Present findings through charts and visualizations.

## Tools and Technologies
- Python
- Pandas
- Data Visualization
- Google Colab

## Project Workflow
- Cleaned and prepared the dataset.
- Handled missing values and duplicate records.
- Analyzed crime categories, time periods, and geographical areas.
- Created visualizations to communicate the findings.

## Project Files
- `CrimeLens_EDA.ipynb` – Jupyter notebook containing the analysis.

## Team Project
This project was completed collaboratively as part of an academic project.

Los Angeles crime data covering 2020–2024.
